# Checklist — Project Quality Bootstrap

## Descoberta

- [ ] Instruções do repositório foram lidas
- [ ] Skills locais existentes foram inventariadas
- [ ] Manifests, lockfiles e arquivos de projeto foram identificados
- [ ] Scripts e comandos da CI foram comparados
- [ ] Estrutura e framework de testes foram confirmados

## Evidências

- [ ] Cada comando proposto possui origem citada
- [ ] Comandos locais e de CI não divergem sem explicação
- [ ] Dependências, serviços e variáveis necessários foram descritos
- [ ] Itens desconhecidos viraram perguntas, não suposições

## Proposta

- [ ] Matriz de capacidades classificada
- [ ] Skill proposta não duplica skill existente
- [ ] Preview completo apresentado
- [ ] Nenhum marcador `{{...}}` permanece no conteúdo final
- [ ] Caminho de destino usa `.agents/skills/<nome>/SKILL.md`

## Escrita

- [ ] Confirmação explícita obtida para este arquivo
- [ ] Destino verificado novamente antes da criação
- [ ] Nenhum arquivo existente foi sobrescrito
- [ ] Diff final apresentado ao usuário
- [ ] Commit, push e PR não foram executados automaticamente
